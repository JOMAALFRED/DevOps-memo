# DevOps-memo

## Sujet

Mise en œuvre d'une architecture Kubernetes hautement
disponible avec stratégies de déploiement Blue-Green et Canary.

## Objectifs

- Construire une infrastructure Kubernetes hautement disponible.
- Déployer une application conteneurisée.
- Mettre en œuvre Blue-Green Deployment.
- Mettre en œuvre Canary Deployment.
- Automatiser les déploiements avec CI/CD et GitOps.
- Surveiller les performances avec Prometheus et Grafana.
- Réaliser des tests de panne et de récupération.

## Technologies

- Docker
- Kubernetes / K3s
- HAProxy
- Argo CD
- Argo Rollouts
- GitHub Actions
- Prometheus
- Grafana
- Trivy
